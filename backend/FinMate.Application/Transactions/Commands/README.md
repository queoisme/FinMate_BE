Đường mới tạo, xoá, gộp hay chuyển đổi giao dịch phải gọi các đồng bộ liên quan (`IGroupLedger`, `IDuplicateDetector`, `ILoanLinkSync`, `IRecurringPaymentSync`, …), danh sách ở `CLAUDE.md`.
