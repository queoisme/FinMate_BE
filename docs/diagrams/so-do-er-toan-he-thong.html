Phân hệ 1

Xác thực, Người dùng & Bảo mật (Auth & Security)

Quản lý định danh, phiên đăng nhập, điều khoản và lịch sử truy vết
# users ROOT ENTITY
  • # idUUID PK
  • · emailVARCHAR UK
  • · phoneVARCHAR UK
  • · password_hashVARCHAR
  • · full_nameVARCHAR
  • · roleVARCHAR ('USER','ADMIN')
  • → privacy_policy_versionVARCHAR FK
  • · encrypted_dek_backupTEXT (E2EE)
  • · created_at / updated_atTIMESTAMPTZ
Liên kết:
1 — N → tài khoản, giao dịch, ngân sách, gamification
# privacy_policy_versions POLICY
  • # versionVARCHAR PK
  • · content_markdownTEXT
  • · effective_dateTIMESTAMPTZ
  • · is_mandatory_reacceptBOOLEAN
Liên kết:
1 — N → users
# refresh_tokens JWT AUTH
  • # idUUID PK
  • → user_idUUID FK
  • · token_hashVARCHAR UK
  • · device_fingerprintTEXT
  • · expires_at / is_revokedTIMESTAMPTZ / BOOL
Liên kết:
N — 1 → users
# otp_verifications SECURITY
  • # idUUID PK
  • · contactVARCHAR (Email/Phone)
  • · otp_hashVARCHAR

N — 1 → users

  • # idUUID PK

  • · actionVARCHAR ('CONFIRM', 'VOID'...)

Phân hệ 3

Thu nhận Thông báo & AI Bóc tách (Flow 1 Ingestion)

Lắng nghe biến động số dư, trích xuất thực thể AI và học quy tắc đối tác
# notification_logs LOGS
  • # idUUID PK
  • → user_idUUID FK
  • → financial_account_idUUID FK
  • · content_hashVARCHAR(64) (Idempotency)
  • · raw_text / titleTEXT (E2EE/Normalized)
  • · statusVARCHAR ('PENDING','PROCESSED'...)
  • · received_atTIMESTAMPTZ
Liên kết:
1 — 1 → ai_results 0..1 — N → transactions
# ai_results AI SERVICE
  • # idUUID PK
  • → notification_log_idUUID FK (1-1)
  • · amount_centsBIGINT (Trích xuất)
  • · category_slugVARCHAR (Gợi ý)
  • · extraction_confidenceREAL (≥0.85 Auto-commit)
  • · recipient_account_hashVARCHAR (HMAC PII)
  • · transaction_subtypeVARCHAR ('purchase','transfer')
Liên kết:
1 — 1 → notification_logs Hash match ⤏ counterparty_category_rules
# categories TAXONOMY
  • # idUUID PK
  • → user_idUUID FK (NULL if System)
  • → parent_idUUID FK (Cây cha-con)
  • · name / slugVARCHAR
  • · category_typeVARCHAR ('INCOME','EXPENSE')
  • · is_systemBOOLEAN (Không được xóa)
Liên kết:
1 — N → transactions, budgets, rules
# counterparty_category_rules FLOW 1 UPDATE
  • # idUUID PK
  • → user_idUUID FK
  • → category_idUUID FK
  • · providerVARCHAR ('VCB', 'MB'...)
  • · counterparty_account_hashVARCHAR (HMAC-SHA256)
  • · counterparty_nameVARCHAR
  • · is_activeBOOLEAN
Liên kết:
N — 1 → users, categories Auto-assign ⤏ transactions
Phân hệ 4

Sổ cái Giao dịch Trung tâm (Transactions Ledger)

Thực thể trung tâm tiếp nhận từ mọi nguồn (Flow 1 Auto, Flow 2 Manual/OCR/Voice)
# transactions SYSTEM CORE LEDGER
  • # idUUID PK
  • → user_idUUID FK
  • → financial_account_idUUID FK (Ví nguồn)
  • → counter_account_idUUID FK (Ví đích nội bộ, null)
  • → category_idUUID FK (Nullable)
  • → notification_log_idUUID FK (Nullable)
  • · amount_centsBIGINT (Null nếu draft)
  • · transaction_typeVARCHAR ('debit', 'credit')
  • · transaction_subtypeVARCHAR ('purchase', 'transfer'...)
  • · statusVARCHAR ('draft', 'confirmed', 'voided')
  • · confirmation_modeVARCHAR ('auto', 'manual')
  • · sourceVARCHAR ('notification','manual','ocr','voice')
  • · category_assignment_sourceVARCHAR ('rule','ai','user','default')
  • · undo_expires_atTIMESTAMPTZ (5 phút cửa sổ)
  • · voided_at / voided_reasonTIMESTAMPTZ / TEXT
  • · transacted_atTIMESTAMPTZ
  • · note_encryptedTEXT (E2EE)
Mối quan hệ trung tâm:
Nhận nguồn từ: users, financial_accounts, categories, notification_logs Cập nhật số dư sang: financial_accounts.balance_cents Cập nhật tiến độ: budgets, daily_summaries, savings_goals
